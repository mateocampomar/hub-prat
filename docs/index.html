PRAT

Instalación audiovisual sincronizada — showroom de baños, Montevideo. Un botón inalámbrico dispara video en TV vertical + luz LED + ventilador + sonido, en loop autónomo.

Hardware

Topología, reglas de instalación y pendientes de armado. Pi 5 + ESP32 + ESP-NOW.

Pipeline de video

Normalización a 29.97 CFR, panel de render y validación en la TV.

El sistema en una línea

[Botón ESP-NOW] → [Raspberry Pi 5] → TV vertical + LED WS2812B + ventilador + parlante

Restricción dura: cero tensión de red dentro del baño — todo baja tensión. El render corre en la Mac mini, y el panel se accede desde cualquier lado por el túnel de Cloudflare.
